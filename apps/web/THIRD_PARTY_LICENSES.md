## Patterns re-implemented (no code copied)

These components were written from scratch for BursarBridge, inspired by ideas published under MIT:
- `NumberTicker` (`src/components/bb/ticker.tsx`): idea from Magic UI's Number Ticker (MIT).
- Shimmer text (`.shimmer-text` utility): idea from Magic UI's Animated Shiny Text (MIT).
- Money path (`src/components/bb/money-path.tsx`): idea from Magic UI's Animated Beam (MIT).

## Fonts

Self-hosted at build time by `next/font/google`:
- Be Vietnam Pro, SIL Open Font License 1.1.
- JetBrains Mono, SIL Open Font License 1.1.

Korean and Chinese text falls back to the device's system fonts (Apple SD Gothic Neo, Malgun Gothic, PingFang SC, Microsoft YaHei, Noto Sans KR/SC); nothing is bundled for those scripts.

## Generated assets

- `public/samples/live/*`: synthetic demo documents copied from the API's `evidence/fixtures/` (this repository). Every organisation in them is fictional.
- Open Graph image: rendered at request time by `src/app/opengraph-image.tsx` (this repository).
